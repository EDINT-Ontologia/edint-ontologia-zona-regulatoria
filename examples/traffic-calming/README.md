# Ejemplos de Zonas de Pacificación del Tráfico (TrafficCalmingZone)

Este directorio contiene datos de ejemplo que instan la clase `TrafficCalmingZone` del vocabulario SKOS `RegulatedZoneType`.

## Ejemplos incluidos

- `example_calmaria.ttl`: Superilla Mercat de la Libertat (Barcelona) y zona de pacificación del centro de Vitoria-Gasteiz.
